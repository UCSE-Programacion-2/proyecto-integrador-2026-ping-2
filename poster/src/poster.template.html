TECNO X

La tienda online de un comercio de tecnología de Jujuy.

Problema

Tecno X vende celulares, parlantes y accesorios en su local y por redes sociales, pero no tenía una tienda propia para mostrar su catálogo y vender online.

Objetivos

  • Que el cliente encuentre un producto, lo sume al carrito y compre desde el celular.
  • Que el comercio cargue, edite y dé de baja sus productos sin escribir código.

Cómo funciona

TiendaReact + Vite · Vercel
API RESTExpress + JWT · Render
Base de datosMongoDB · Atlas

Cuatro sprints con Scrum: cada tarea es un issue, una rama y un pull request con revisión de código.

Estado de avance

  1. Idea y diseño
  2. En desarrollo
  3. Prototipo funcional
  4. Resultados preliminares

Ya funciona en producción.

Próximos pasos

  • Cobrar online con Mercado Pago.
  • Descontar el stock al confirmar cada compra.
  • Probar la tienda con clientes reales del local.
